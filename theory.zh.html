02 / FIELD NOTES

群、环与域

集合与满足特定规则的运算一起构成代数结构。

结构规则例子
群一种满足封闭性、结合律的运算，存在单位元，每个元素都有逆元；阿贝尔群还满足交换律。模 7 整数的加法群中，单位元为 0，3 的加法逆元为 4。
环加法构成阿贝尔群，乘法满足结合律和对加法的分配律；本节采用带乘法单位元 1 的交换环。ℤ₈ 按模 8 做加法和乘法，部分非零元素没有乘法逆元。
域0 ≠ 1 的交换环中，每个非零元素都有乘法逆元；除以非零元素等价于乘它的逆元。GF(7) 按模 7 运算，3 的逆元是 5，因为 3·5 ≡ 1。

对模 n 的剩余类，a 存在乘法逆元的充要条件是 gcd(a,n) = 1。扩展 Euclid 求出 au + nv = 1，u mod n 即逆元。零因子是能与另一个非零元素相乘得到零的非零元素。

GF(7): 3·5 = 15 ≡ 1; 2/3 = 2·5 ≡ 3 ℤ₈: 2·4 ≡ 0; 2 has no multiplicative inverse ℤ₈: 3·3 = 9 ≡ 1; 3 is invertible

域中的非零元素在乘法下构成群；环中的可逆元素组成单位群。注意分别识别加法逆元 −a 和乘法逆元 a⁻¹。

03 / FIELD NOTES

有限域与伽罗华域

GF(q) 与 𝔽q 都表示具有 q 个元素的有限域。

有限域也称伽罗华域，元素个数必为 pᵐ，其中 p 为素数、m ≥ 1。每种这样的大小都存在有限域，且在同构意义下唯一；基和多项式的选择会改变元素的编码。其特征为 p，即把 1 相加 p 次得到 0。

构造表示方式运算例子
GF(p)p 为素数，使用 0…p−1 的剩余类，加法和乘法均模 p 约减。GF(7): 5+4 = 2; 5·4 = 6
GF(pᵐ)使用 GF(p) 上次数小于 m 的多项式，乘积对选定的 m 次不可约多项式取余。GF(8) = GF(2)[x]/(x³+x+1)
ℤ/(pᵐ)ℤ整数按模 pᵐ 运算，m > 1 时存在零因子。ℤ₈: 2·4 = 0

构造 GF(8) 时选 f(x) = x³+x+1。它在 GF(2) 中没有根，对三次多项式这足以证明不可约。八个代表元为 0、1、x、x+1、x²、x²+1、x²+x、x²+x+1，此时 x³ 约减为 x+1。

GF(8), f(x) = x³+x+1: (x²+1)(x+1) = x³+x²+x+1 ≡ x² x·(x²+1) = x³+x ≡ 1 Therefore x⁻¹ = x²+1

比较所选表示中的 2 和 4：在 GF(8) 中，它们表示 x 和 x²，乘积为 x³ ≡ x+1，编码为 3；在 ℤ₈ 中，整数乘积模 8 得到 0。必须根据结构与表示方式确定运算。

04 / FIELD NOTES

在 GF(2⁸) 中计算一个字节

AES 把每个字节表示为二进制系数多项式。

比特 bᵢ 是 xⁱ 的系数，最低有效位对应常数项。加法的系数按模 2 相加，因此就是 XOR，再加一次即可消去。乘法先做无进位多项式乘法，再对 AES 多项式 x⁸+x⁴+x³+x+1 取余，其编码为 0x11b。

0x57 = 01010111₂ = x⁶+x⁴+x²+x+1 0x83 = 10000011₂ = x⁷+x+1 Addition: 0x57 ⊕ 0x83 = 0xd4 Multiplication: 0x57 · 0x83 = 0xc1 in the AES field Inverse: 0x53 · 0xca = 0x01 in the AES field

AES 的 xtime 表示乘 x：左移并丢弃最高位，原最高位为 1 时再异或 0x1b。一般乘法可把这些逐次倍乘的结果按乘数比特异或起来。下面的小程序展示算术，AES 的 S 盒求逆步骤和 MixColumns 都使用该域。

def gf256_mul(a, b):
    result = 0
    for _ in range(8):
        if b & 1:
            result ^= a
        high_bit = a & 0x80
        a = (a << 1) & 0xff
        if high_bit:
            a ^= 0x1b
        b >>= 1
    return result

assert gf256_mul(0x57, 0x83) == 0xc1
assert gf256_mul(0x53, 0xca) == 1

本例假定输入为字节，代码用于教学。密码软件还需要具备合适侧信道行为的实现。GHASH 与 XTS tweak 乘法使用 GF(2¹²⁸)，各模式自行规定比特和字节表示。

05 / FIELD NOTES

RSA、椭圆曲线与格密码中的环

分别检查数据、指数及标量所在的数学结构。

RSA 按合数 n = pq 取模。在 ℤₙ 中，与 n 互素的剩余类组成乘法单位群，其他非零剩余类可能是零因子。椭圆曲线点坐标在域中计算，标量运算使用相关点子群的阶，这些模数承担不同职责。

多项式商环 R = 𝔽q[x]/(f) 中，系数按素数 q 取模，多项式再对 f 取余。f 不可约时商环构成域。gcd(a(x),f(x)) = 1 时，a(x) 在商环中可逆。以 GF(5) 上 f(x) = x²−1 为例，x−1 与 x+1 都非零，但相乘后在商环中得到零。

R = GF(5)[x]/(x²−1) (x−1)(x+1) = x²−1 ≡ 0 x² ≡ 1 (x+1)² = x²+2x+1 ≡ 2x+2

格密码方案常用多项式商环及其上的向量组织高效运算。入门时可分别追踪系数约减和多项式约减，相关困难性假设详见独立的格密码专题。

06 / FIELD NOTES

唯密文、已知明文与选择输入攻击

攻击模型规定对手已知的信息及可调用的 Oracle。

Oracle（预言机）是回答查询但隐藏秘密密钥的抽象接口。加密 Oracle 在目标密钥下加密攻击者选择的消息；解密 Oracle 返回模型允许的解密结果。实际服务也可能只泄露有效性或时序信号。公钥加密中，任何人都能用公钥执行加密。

模型已知信息或可查询内容典型情形
COA · 唯密文攻击密文、公开算法及可能消息的背景知识。观察加密流量或存储密文。
KPA · 已知明文攻击除目标密文外，已知目标密钥下的一些真实明文—密文对。已知文件头，或在其他地方公开的文档。
CPA · 选择明文攻击选择消息并获得目标密钥下的加密结果；自适应查询可根据先前回答继续选择。向会加密输入的服务提交可控数据。
CCA · 选择密文攻击选择密文并获得允许的解密结果；在挑战游戏中，禁止直接查询目标挑战密文本身。解密服务接收可控密文，模型进一步规定允许查询的时机。

CCA 的两种常见细分

  • CCA1。解密查询能力在挑战前结束，此前的查询仍可根据先前回答调整。又称午餐攻击或非自适应 CCA，时间限制以挑战为界。
  • CCA2。看到挑战后仍可继续自适应查询解密，但始终禁止直接查询挑战密文本身。

这些名称描述攻击者能力，安全目标要求方案在这些能力下仍保护指定属性。恢复密钥、恢复明文、区分消息与伪造可接受密文是不同的成功目标，还应规定密钥范围、查询预算及允许的反馈。

07 / FIELD NOTES

四种攻击的具体算例

每个例子都说明某种构造在特定能力下暴露的弱点。

COA 与语言结构

Caesar 密码将字母映射为 (letter + k) mod 26。只有密文 KHOOR 时，可枚举 26 种移位，k = 3 得到可能的英文候选 HELLO。更多密文还能提供频率和词形证据。推断依赖语言冗余与很小的密钥空间。

KPA 与重复使用的 XOR 密钥流

Known P = 41 42 43; C = 51 62 73 (hex) S = P XOR C = 10 20 30 Another ciphertext using the same S: C₂ = 54 65 76 P₂ = C₂ XOR S = 44 45 46 (ASCII DEF)

已知明密文对可恢复覆盖该片段的密钥流字节。另一条消息在相同偏移复用时，这些字节可继续用于恢复明文；对重复使用的流密码密钥流，同样可分析被暴露的区间。

CPA 与确定性 ECB 加密

选择两个不同的 16 字节块 m₀、m₁，先查询 E = Enc(k,m₀)。挑战方用同一密钥加密其中一个。挑战密文等于 E 时可判断是 m₀，否则是 m₁，因为分组密码置换会把两个不同块映射成不同密文。

E = Enc(k, m₀) c* = Enc(k, m_b), with uniform b ∈ {0,1} guess b = 0 if c* == E, otherwise 1 Success probability = 1 for this deterministic single-block example

CCA 与裸 RSA 的可塑性

裸 RSA 将 m 加密为 c = mᵉ mod n。收到目标 c* 后，选择可逆的 r，查询 c′ = c*·rᵉ mod n 的解密，并确保 c′ 与 c* 不同。回答是 mr mod n，再乘 r⁻¹ 即可恢复 m。下面采用 n = 55、e = 3、d = 27 的小数值。

m = 2; c* = 2³ mod 55 = 8 r = 2; r⁻¹ mod 55 = 28 c′ = 8·2³ mod 55 = 9 D(c′) = 9²⁷ mod 55 = 4 m = 4·28 mod 55 = 2

这个查询依赖已见到的挑战密文，体现 CCA2 能力。RSA-OAEP 通过规定的编码构成另一套加密方案，需要按其安全分析理解。实际系统的填充错误差异或时序也可能泄露部分解密反馈，因此响应接口同样需要纳入模型。

09 / FIELD NOTES

归约把失败转移到安全假设

这是条件推理，不是无条件保证。

证明构造一个算法，利用成功的攻击者求解假定困难的问题，或破坏底层原语。应看查询上限、归约损失、随机 Oracle 或理想密码假设及参数大小。RSA 安全不能简单视为与因数分解的一般等价关系；离散对数、DH 与格假设也不同。IND-CPA 本身不意味着完整性。

让模型对应实现

抽象证明可能未建模时序、故障、解析、弱随机性、密钥泄漏或回滚。应明确这些假设，并检查实际边界。

10 / FIELD NOTES

完美保密与计算保密

一次一密用严格的密钥管理换取很强的性质。

至少与消息等长、均匀且独立并只用一次的密钥，给一次一密带来完美保密性；但不提供完整性。流密码用短秘密派生的计算伪随机性替代长密钥垫，安全假设及 key/nonce 规则随之改变。两者都不应被自制成认证协议的替代品。
