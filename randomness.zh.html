01 / FIELD NOTES

熵支撑确定性扩展

DRBG 可产生大量比特，而非每一位都产生新物理熵。

噪声源、调理及健康测试提供种子材料。密码 DRBG 演化状态并产生伪随机输出；安全依赖熵、算法和状态保护。SP 800-90B 讨论熵源，90A 定义 DRBG 机制，90C 把它们组合为 RBG 构造。统计上“像随机”本身不能证明不可预测。

H_min(X) = −log₂(max_x Pr[X=x]) A 256-bit output does not imply a 256-bit unpredictable seed

随机与唯一不是同义词

所需属性由构造决定。

03 / FIELD NOTES

通过受支持接口使用 OS CSPRNG

Python 中 secrets 是面向秘密值的接口。

import secrets
key = secrets.token_bytes(32)
token = secrets.token_urlsafe(32)
index = secrets.randbelow(10)  # unbiased range sampling

不要用时间给 PRNG 播种，也不要用 random / Math.random 生成密钥。随机字节直接对范围取模可能引入偏置。嵌入式与早期启动需明确的熵就绪设计；进程 fork、快照和恢复生成器状态需要实现支持。硬件 RNG 指令是需要评估的输入或接口，并非通用熵证明。
