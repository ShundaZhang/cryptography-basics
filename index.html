01 / ROUTE

A route with useful stopping points

Assumed background: basic programming, binary data and a working understanding of computer systems. Learn the mathematical tools as they arise.

01

Get oriented in a few evenings

Read Foundations, Symmetric, Public key, Hash / MAC / KDF and Randomness. Run the four labs. You should be able to explain what encryption, authentication and freshness each guarantee.

02

Read real systems next

Choose TLS or SPDM according to your work. Trace key establishment, identity verification, transcript binding and failure paths. Then read Applied crypto and review a small design.

03

Build depth over four to six weeks

Add Theory and History, work through selected textbook sections, and study Future. This is a suggested pace, not a prerequisite chain: every topic has its own entry point.

What you should be able to review

Which property is required? Who holds each key? Where does entropy come from? Which bytes are authenticated? How is replay rejected? What happens after compromise or restart?
