02 / FIELD NOTES

Algorithms process bytes, not visual meaning

Encoding choices are part of the security design.

Hex and Base64 are representations, not encryption. UTF-8, normalization, field boundaries, byte order and signed serialization must be agreed on. The strings “ab” + “c” and “a” + “bc” collide under naïve concatenation even without a hash collision. Use a specified, unambiguous encoding and domain labels.

encode(protocol_id, version, role, length(field_1), field_1, length(field_2), field_2)

03 / FIELD NOTES

Read parameters before comparing “bits”

Key size, block size, digest size and estimated security are different quantities.

AES-256 still has a 128-bit block. A 256-bit hash has a generic classical collision cost around 2^128, not 2^256. A 2048-bit RSA modulus and a 256-bit elliptic-curve field do not represent comparable key lengths by simple counting. Use the algorithm’s security analysis, parameter set and usage limits.

A primitive is a building block

A protocol adds identity, negotiation, transcript binding, state transitions and failure behavior. A successful decrypt or signature check is not the whole protocol.
