02 / FIELD NOTES

Groups, rings and fields

A set becomes an algebraic structure when its operations satisfy specific rules.

StructureRulesExample
GroupOne closed, associative operation, an identity and an inverse for every element. An abelian group also has commutativity.The additive group of integers modulo 7 has identity 0 and additive inverse −3 ≡ 4.
RingAddition is an abelian group; multiplication is associative and distributes over addition. Here we use commutative rings with multiplicative identity 1.ℤ₈ has addition and multiplication modulo 8. Some nonzero elements have no multiplicative inverse.
FieldA commutative ring with 0 ≠ 1 in which every nonzero element has a multiplicative inverse. Division by a nonzero element is multiplication by its inverse.GF(7) uses arithmetic modulo 7. The inverse of 3 is 5 because 3·5 ≡ 1.

For residues modulo n, an element a has a multiplicative inverse exactly when gcd(a,n) = 1. Extended Euclid finds integers u,v with au + nv = 1, so u mod n is the inverse. A zero divisor is a nonzero element that multiplies another nonzero element to zero.

GF(7): 3·5 = 15 ≡ 1; 2/3 = 2·5 ≡ 3 ℤ₈: 2·4 ≡ 0; 2 has no multiplicative inverse ℤ₈: 3·3 = 9 ≡ 1; 3 is invertible

The nonzero elements of a field form a multiplicative group. In a ring, the invertible elements form the group of units. These distinguish the additive inverse −a from the multiplicative inverse a⁻¹.

03 / FIELD NOTES

Finite fields and Galois fields

GF(q) and 𝔽q name a field with q elements.

A finite field is also called a Galois field. Its size is pᵐ, where p is prime and m ≥ 1. For each such size a field exists and is unique up to isomorphism. Different choices of basis and polynomial change the encoding of its elements. The characteristic is p, so adding 1 to itself p times gives 0.

ConstructionRepresentationArithmetic example
GF(p)For prime p, use residues 0…p−1. Reduce addition and multiplication modulo p.GF(7): 5+4 = 2; 5·4 = 6
GF(pᵐ)Use polynomials of degree below m over GF(p). Reduce products modulo a chosen irreducible degree-m polynomial.GF(8) = GF(2)[x]/(x³+x+1)
ℤ/(pᵐ)ℤReduce integers modulo pᵐ. For m > 1 this has zero divisors.ℤ₈: 2·4 = 0

To build GF(8), pick f(x) = x³+x+1. It has no root in GF(2), which proves irreducibility for this cubic. The eight representatives are 0, 1, x, x+1, x², x²+1, x²+x, x²+x+1. In this representation x³ reduces to x+1.

GF(8), f(x) = x³+x+1: (x²+1)(x+1) = x³+x²+x+1 ≡ x² x·(x²+1) = x³+x ≡ 1 Therefore x⁻¹ = x²+1

Compare the chosen representations of 2 and 4. In GF(8), 2 denotes x and 4 denotes x², so their product is x³ ≡ x+1, encoded as 3. In ℤ₈, the integer product reduces to 0. The notation and representation determine the operations.

04 / FIELD NOTES

Compute a byte in GF(2⁸)

AES represents each byte as a polynomial with binary coefficients.

The bit bᵢ is the coefficient of xⁱ, with the least significant bit as the constant term. Addition adds coefficients modulo 2, so it is XOR and is its own inverse. Multiplication first forms a carry-less polynomial product, then reduces it modulo the AES polynomial x⁸+x⁴+x³+x+1, encoded as 0x11b.

0x57 = 01010111₂ = x⁶+x⁴+x²+x+1 0x83 = 10000011₂ = x⁷+x+1 Addition: 0x57 ⊕ 0x83 = 0xd4 Multiplication: 0x57 · 0x83 = 0xc1 in the AES field Inverse: 0x53 · 0xca = 0x01 in the AES field

Multiplication by x, called xtime in AES, shifts left and conditionally XORs 0x1b after discarding the high bit. General multiplication can XOR together these successive multiples. The small routine below illustrates the arithmetic. AES uses this field in its S-box inverse step and MixColumns.

def gf256_mul(a, b):
    result = 0
    for _ in range(8):
        if b & 1:
            result ^= a
        high_bit = a & 0x80
        a = (a << 1) & 0xff
        if high_bit:
            a ^= 0x1b
        b >>= 1
    return result

assert gf256_mul(0x57, 0x83) == 0xc1
assert gf256_mul(0x53, 0xca) == 1

This routine assumes byte inputs and is a teaching example. Cryptographic software needs an implementation with suitable side-channel behavior. GF(2¹²⁸) also appears in GHASH and XTS tweak multiplication, with each mode defining its own bit and byte representation.

05 / FIELD NOTES

Rings in RSA, elliptic curves and lattice cryptography

Check which structure contains the data and which contains the exponents or scalars.

RSA computes modulo a composite n = pq. In ℤₙ, residues coprime to n form the multiplicative unit group; other nonzero residues can be zero divisors. Elliptic-curve point coordinates are calculated in a field, while scalar arithmetic uses the order of the relevant point subgroup. Those moduli play separate roles.

For a polynomial ring quotient R = 𝔽q[x]/(f), reduce coefficients modulo prime q and polynomials modulo f. The quotient is a field exactly when f is irreducible. A residue a(x) is invertible when gcd(a(x),f(x)) = 1. With f(x) = x²−1 over GF(5), x−1 and x+1 are nonzero, but their product is zero in the quotient.

R = GF(5)[x]/(x²−1) (x−1)(x+1) = x²−1 ≡ 0 x² ≡ 1 (x+1)² = x²+2x+1 ≡ 2x+2

Lattice schemes often use polynomial quotient rings and vectors over them to organize efficient arithmetic. For an introductory view, track coefficient reduction and polynomial reduction separately. The dedicated lattice-cryptography site covers the associated hardness assumptions.

06 / FIELD NOTES

Ciphertext-only, known-plaintext and chosen-input attacks

An attack model states the information and oracle access available to the adversary.

An oracle is an abstract interface that answers a query without revealing the secret key. An encryption oracle returns an encryption of an attacker-chosen message under the target key. A decryption oracle returns permitted decryptions. In practice, a service may reveal only a validity result or a timing signal. Public-key encryption lets anyone encrypt with the public key.

ModelAvailable information or queryTypical setting
COA · Ciphertext-onlyCiphertexts, public algorithms and background knowledge about possible messages.Observe encrypted traffic or stored ciphertext.
KPA · Known-plaintextSome genuine plaintext–ciphertext pairs encrypted under the target key, alongside the target ciphertext.A known file header or a separately published document.
CPA · Chosen-plaintextChoose messages and obtain their encryptions under the target key. Adaptive queries may depend on earlier answers.Submit controlled data to a service that encrypts it.
CCA · Chosen-ciphertextChoose ciphertexts and obtain permitted decryption results. In a challenge game, querying the target challenge ciphertext itself is excluded.A decryption service accepts controlled ciphertexts. The model specifies when queries are allowed.

Two common CCA variants

  • CCA1. Decryption access ends before the challenge. Earlier queries may depend on earlier answers. It is also called lunchtime or non-adaptive CCA, with the timing restriction defined relative to the challenge.
  • CCA2. Decryption queries remain available after seeing the challenge and can be chosen adaptively, with the challenge ciphertext itself excluded.

These names describe capabilities. A security goal asks a scheme to protect the chosen property even with those capabilities. Key recovery, plaintext recovery, distinguishing messages and forging accepted ciphertexts are different success goals. Define the key scope, query budget and allowed feedback alongside the goal.

07 / FIELD NOTES

Four small attacks, worked through

Each example exposes a weakness of the stated construction under a particular capability.

COA through language structure

A Caesar cipher maps letters to (letter + k) mod 26. Given only KHOOR, enumerate the 26 shifts. The shift k = 3 yields HELLO, a plausible English candidate. More ciphertext gives frequency and word-pattern evidence. The inference uses language redundancy and the tiny key space.

KPA against a reused XOR pad

Known P = 41 42 43; C = 51 62 73 (hex) S = P XOR C = 10 20 30 Another ciphertext using the same S: C₂ = 54 65 76 P₂ = C₂ XOR S = 44 45 46 (ASCII DEF)

A known pair reveals the pad bytes covering that pair. Reuse at the same offset makes those bytes useful against another message. Recovering these bytes also describes the exposed region of a reused stream-cipher keystream.

CPA against deterministic ECB encryption

Choose two distinct 16-byte blocks m₀ and m₁. Ask the encryption oracle for E = Enc(k,m₀). The challenge encrypts one of the two under the same key. Compare the challenge ciphertext with E. Equality identifies m₀; inequality identifies m₁. A block-cipher permutation gives distinct outputs for the two distinct blocks.

E = Enc(k, m₀) c* = Enc(k, m_b), with uniform b ∈ {0,1} guess b = 0 if c* == E, otherwise 1 Success probability = 1 for this deterministic single-block example

CCA through textbook RSA malleability

Textbook RSA encrypts m as c = mᵉ mod n. After receiving target c*, choose an invertible r and request decryption of c′ = c*·rᵉ mod n, with c′ distinct from c*. The answer is mr mod n. Multiply by r⁻¹ to recover m. The small arithmetic below uses n = 55, e = 3, d = 27.

m = 2; c* = 2³ mod 55 = 8 r = 2; r⁻¹ mod 55 = 28 c′ = 8·2³ mod 55 = 9 D(c′) = 9²⁷ mod 55 = 4 m = 4·28 mod 55 = 2

This query is constructed after seeing the challenge, illustrating CCA2 access. RSA-OAEP defines a padded encryption scheme with a separate security analysis. In real systems, differentiated padding errors or timing can also expose partial decryption feedback, so the actual response interface belongs in the model.

09 / FIELD NOTES

A reduction transfers a failure to an assumption

It is conditional reasoning, not an unconditional guarantee.

A proof constructs an algorithm that uses a successful attacker to solve an assumed-hard problem or break a lower-level primitive. Inspect query limits, reduction loss, random-oracle or ideal-cipher assumptions and parameter sizes. RSA security is not simply a general equivalence to factoring; discrete-log, DH and lattice assumptions are distinct. IND-CPA alone does not imply integrity.

Match the model to implementation

An abstract proof may not model timing, faults, parsing, weak randomness, key compromise or rollback. State those assumptions and test the actual boundary.

10 / FIELD NOTES

Perfect secrecy and computational secrecy

A one-time pad buys a strong property with demanding key management.

A uniform independent key at least as long as the message, used only once, gives one-time-pad perfect secrecy. It does not provide integrity. Stream ciphers replace the long pad with computational pseudorandomness from a short secret; the assumptions and key/nonce rules change. Neither construction should be deployed as a homemade replacement for an authenticated protocol.
